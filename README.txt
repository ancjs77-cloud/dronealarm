드론경보 (PRD "비행장 드론 위협 경보·행동지시 앱" 오프라인 시연판)
※ 모든 부대·인원·절차 정보는 시연용 가상 데이터입니다.

[구성]
- index.html            : 앱 본체(화면·판단 규칙·시뮬레이터·보고서). PC 크롬에서 바로 열 수 있음
- android_apk/          : 갤럭시 설치용 APK 껍데기(WebView). assets/index.html 이 위 파일과 같음
  - build_apk.sh        : APK 다시 만들기 (apktool 2.10.0, uber-apk-signer 1.3.0, Java 17)

[갤럭시 설치 (USB 없이)]
1. DroneAlarm.apk 를 휴대폰으로 보냅니다 (카카오톡 '나에게 보내기', 구글 드라이브, 이메일 등)
2. 설정 > 보안 및 개인정보 보호 > 자동 차단기 > 끔 (켜져 있으면 설치가 막힘)
3. 휴대폰에서 APK 파일을 누름 > "출처를 알 수 없는 앱" 허용 > 설치
4. Play 프로텍트 경고가 나오면 "무시하고 설치"
5. 배터리: 설정 > 애플리케이션 > 드론경보 > 배터리 > 제한 없음

[이글루 대피 (3단계 경계에서 즉시 대피)]
- 조종사: 가장 가까운 '빈' 이글루(항공기 없음·미배정)가 자동 배정 → 도착 후 [도착·입고 완료] (필요 시 [다른 이글루])
- 정비사: 가장 가까운 열린 이글루로 대피 → [입실] → [Close 완료]. 상황 해제 후 [Open 완료]
- 상황실: 이글루별 상태(비어 있음·배정·항공기 입고·대피 N명·닫힘·사용 불가) 지도와 표, '개방 처리'·'사용 불가'·'항공기 있음' 설정
- 위치: 휴대폰 GPS (첫 실행 시 위치 권한 '앱 사용 중에만 허용'). 비행장 기준점 5km 밖이면 시연용 가상 위치 사용
- 이글루 위치는 시연용 가상 배치(10개)가 기본값입니다. 실제 위치는 상황실 화면에서 각 이글루 앞에 서서
  '현재 위치에 이글루 추가(GPS)'로 등록하세요(그 단말에만 저장). '내 주변에 시연 배치 만들기'로 아무 곳에서나 GPS 시연 가능

[PC 에뮬레이션]
- 드론경보_PC.html 을 크롬으로 열기 > PIN 1234 > 바로 시연 보드(왼쪽 상황실 + 휴대폰 3대: 조종사·정비사·방호관계자)
- 상황 해제 후 정비사가 이글루 [Open 완료]를 누르면 5초 뒤 자동으로 처음 시연 상태로 돌아감 ([⟲ 처음 상태로] 버튼으로 즉시 복귀 가능)
- 상황실 지도: 활주로(13/31) 기준 타원 경보선, 지형은 모식도(가상). 단계 판정도 활주로 타원 거리 기준
- 상황도: 가상 표적의 지나온 항적·예상 경로·진행 방향과 속도/활주로 중앙까지 거리/도착 예상(활주로 중앙 도달 기준) 표시
- 이글루 상태도: 활주로(흰 윤곽·중심선·13/31), 방위표, 축척, 주요 지점(대구공항 터미널·팔공산·동대구IC·동대구역·대구 시내) 방향·거리 표시. 지점 좌표는 공개 지명의 대략 위치
- 휴대폰 대기 화면: 기지 상황도(상황실과 동일) + 비행장 상세도(활주로·이글루·내 위치). 행동 [완료] 후에는 아래에 상황도(드론 이동·내 위치·나와의 거리, 자동 확대) 표시
- 이글루 10개는 활주로 둘레(양측·양 끝)에 분산된 가상 배치
- 2단계(5km 이내)부터 휴대폰은 '이글루 위치 · 내 위치 · 드론' 지도를 계속 표시(배정·대피 이글루까지 노란 점선, 드론은 화면 가장자리에 방향 표시)
- 시연용 가상 위치: 조종사 북동 480m, 정비사 남서 600m, 방호 북서 1.45km (GPS가 있으면 GPS 사용)
  > 상황실 + 휴대폰 4대(조종사·관제사·정비사·방호관계자)가 한 화면에 표시
- 같은 PC에서 크롬 창을 여러 개 열면(상황실 창, 정비사 창 등) 서로 실시간으로 연동됨
